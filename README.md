# SWAP project page

Project page for **SWAP: Test-Time Steerable Humanoid Whole-Body Collision Avoidance**.

Live at <https://iscoyizj.github.io/SWAP-steerable-humanoid-oa-website/> once GitHub Pages is on
(Settings → Pages → Deploy from a branch → `main`, `/ (root)`).

The page is a single static file, `index.html`, with no build step. To update it:

- **Videos:** replace the `<div class="teaser">` block with a `<video>` or `<img>` element.
- **Links:** in the `<ul class="status">` list, replace "coming soon" with links to the paper, code, and videos.
